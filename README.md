# lab10
Iris Flower Classification using SVM

This project focuses on building a Machine Learning model to classify iris flowers into three different species: Setosa, Versicolor, and Virginica. The classification is performed using the Support Vector Machine (SVM) algorithm on the well-known Iris dataset.

The notebook covers the complete machine learning workflow, starting from data loading and preprocessing to data visualization, model training, hyperparameter tuning, and performance evaluation. Different visualization techniques are used to better understand the dataset and analyze feature relationships between flower species.

The project also demonstrates how to improve model accuracy using GridSearchCV for parameter optimization and evaluates the final model using metrics such as confusion matrix and classification report.

Project Objectives
Understand the Iris dataset and its features
Visualize and analyze the dataset
Train an SVM classification model
Optimize model parameters
Evaluate model performance and accuracy
Dataset Features

The dataset contains the following flower measurements:

Sepal Length
Sepal Width
Petal Length
Petal Width

Results

The trained SVM model achieved high classification accuracy in predicting iris flower species. Visualization and evaluation metrics helped analyze the effectiveness of the model and compare prediction results.

Purpose of the Project

This project was created for learning and practicing supervised machine learning concepts, data visualization, and classification model evaluation using Python and Scikit-learn.
